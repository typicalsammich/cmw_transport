# CMW Transport Website

Static landing page for CMW Transport.

## Files
- `index.html`
- `styles.css`
- `script.js`
- `assets/`
- `robots.txt`
- `sitemap.xml`

## Deploy
Upload the contents of this ZIP directly to the root of a GitHub repository.

For Vercel:
1. Import the GitHub repository.
2. Framework preset: Other.
3. No build command is required.
4. Output directory can be left blank.

## Before final launch
Replace the placeholder canonical domain `https://cmwtransport.com/` in:
- `index.html`
- `robots.txt`
- `sitemap.xml`

with the final live domain.
